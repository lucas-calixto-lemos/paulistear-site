# Paulistear · Landing page

Site estático (HTML + CSS + JavaScript), sem dependências de build.

## Estrutura
- `index.html` · conteúdo e textos de todas as seções
- `styles.css` · cores, fontes, tamanhos e layout
- `script.js` · animações (faixas, hélice, transições), mapa, oportunidades e formulários
- `assets/` · logo, marca e foto

## Como ver localmente
Abra `index.html` no navegador (duplo clique).

## Onde editar o conteúdo de exemplo (em `script.js`)
- Pontos do mapa: procure `const PTS`
- Oportunidades: procure `const OPP`
- Áreas do encaminhamento do formulário: procure `const AREAS`
